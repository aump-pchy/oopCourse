หน่วยที่ 2 ตัวแปร ตัวดำเนินการ และการแปลงชนิดข้อมูล

ตัวแปรคือกล่องเก็บข้อมูล ตัวดำเนินการคือสิ่งที่เราทำกับข้อมูลในกล่อง หน่วยนี้มีของให้ลองกดเล่นเยอะ ลองก่อนอ่านเฉลย

จบหน่วยนี้แล้วทำได้

  • ประกาศตัวแปรและค่าคงที่ ตั้งชื่อถูกกฎและถูก convention
  • เขียนนิพจน์และคำนวณผลได้ถูกตามลำดับความสำคัญ
  • แปลงชนิดข้อมูล ทั้งแบบอัตโนมัติและแบบ cast

ชนิดข้อมูลพื้นฐาน

Java มีชนิดข้อมูลพื้นฐาน (primitive) 8 ชนิด ที่ใช้บ่อยที่สุดคือ int, double, char และ boolean

ชนิดขนาดเก็บอะไรตัวอย่าง
byte1 byteจำนวนเต็ม -128 ถึง 127byte b = 100;
short2 bytesจำนวนเต็ม ประมาณ ±32,000short s = 3000;
int4 bytesจำนวนเต็ม ประมาณ ±2,100 ล้านint age = 17;
long8 bytesจำนวนเต็มขนาดใหญ่ ลงท้ายด้วย Llong pop = 66_000_000L;
float4 bytesทศนิยม ลงท้ายด้วย Ffloat f = 2.5F;
double8 bytesทศนิยมความละเอียดสูง (ค่าเริ่มต้นของเลขทศนิยม)double gpa = 3.25;
char2 bytesตัวอักษร 1 ตัว ใช้ ' 'char grade = 'A';
boolean—true หรือ falseboolean passed = true;

String สำหรับข้อความใช้ " " และเป็น object ไม่ใช่ primitive เราจะใช้บ่อยมาก เช่น String name = "Aump";

ประกาศและกำหนดค่า

ต้องประกาศก่อนใช้เสมอ รูปแบบคือ ชนิดข้อมูล ชื่อ = ค่า;

int x = 1;
double radius = 3.14;
char c = 'a';
int y = x + 4 * 3;       // y = 13
int amount = 131 + 14;   // amount = 145
int a, b, total;         // ประกาศหลายตัวพร้อมกัน

var และตัวเลขที่อ่านง่าย

ตั้งแต่ Java 10 ใช้ var ให้คอมไพเลอร์ดูชนิดจากค่าที่กำหนดได้ ใช้ได้กับตัวแปรในเมธอดเท่านั้น และต้องกำหนดค่าทันที ส่วนตัวเลขยาว ๆ ใส่ _ คั่นหลักได้

var count = 10;           // ได้ int
var message = "สวัสดี";    // ได้ String
long budget = 1_500_000L; // เท่ากับ 1500000

การตั้งชื่อ (identifier)

  • ขึ้นต้นด้วยตัวอักษร, _ หรือ $ ห้ามขึ้นต้นด้วยตัวเลข
  • ตัวถัดไปเป็นตัวอักษร ตัวเลข _ หรือ $ ห้ามมีช่องว่างหรือเครื่องหมายอื่น
  • ห้ามตรงกับคีย์เวิร์ด เช่น int, class และห้ามใช้ _ ตัวเดียว
  • ตัวพิมพ์เล็กใหญ่ถือว่าต่างกัน score กับ Score คนละตัว

ค่าคงที่ด้วย final

ใส่ final หน้าชนิดข้อมูล แล้วค่านั้นจะเปลี่ยนไม่ได้อีก ถ้าเผลอกำหนดค่าใหม่ คอมไพล์จะไม่ผ่าน

final int MAX_SCORE = 100;
final float MIN_GPA = 2.0F;
double area = Math.PI * r * r;   // ค่า PI มีให้แล้วใน Math.PI (3.14159...)

ขอบเขตของตัวแปร

ตัวแปรใช้ได้เฉพาะในบล็อก { } ที่ประกาศไว้เท่านั้น

Field (Attribute)Local variable
ประกาศที่ในคลาส นอกเมธอดในเมธอดหรือบล็อก
ใช้ได้ที่ทุกเมธอดในคลาสเฉพาะบล็อกที่ประกาศ
ค่าเริ่มต้นได้ 0, false หรือ null อัตโนมัติไม่มี ต้องกำหนดค่าก่อนใช้
อยู่ได้นานแค่ไหนตามอายุ object (static อยู่ตามอายุคลาส)หายไปเมื่อเมธอดทำงานจบ
 
public class VariableScopeDemo {
    public int i;                 // field

    public void method1() {
        int j = 4;                // local ของ method1
        int k = 2;
    }

    public void method2() {
        int j = 0;                // local ของ method2 (คนละตัวกับข้างบน)
        System.out.println(i);    // ใช้ได้ เพราะ i เป็น field
        // System.out.println(k); // ผิด: k อยู่ใน method1 เท่านั้น
    }
}
แล้วตัวแปรพวกนี้อยู่ตรงไหนในหน่วยความจำ

Local variable อยู่บน Stack ซ้อนกันเป็นชั้นตามเมธอดที่กำลังทำงาน พอเมธอดจบชั้นนั้นก็หายไป ส่วน object ที่สร้างด้วย new และ field ของมันอยู่บน Heap ตัวแปรบน Stack แค่ถือที่อยู่ชี้ไปหา object เรื่องนี้จะชัดขึ้นในหน่วยคลาสและออบเจ็กต์

ตัวดำเนินการคณิตศาสตร์

+ บวก - ลบ * คูณ / หาร % เศษจากการหาร จุดที่พลาดบ่อยที่สุดคือ int หาร int ได้ int เศษทศนิยมหายไปเลย

ห้องทดลองการหาร

ลอง 7 กับ 2, ลอง -7 กับ 2 แล้วลอง b เป็น 0 ทั้งแบบ int และ double

กำหนดค่าแบบย่อ และ ++ --

เขียนย่อความหมาย
x += 3;x = x + 3;
x -= 3;x = x - 3;
x *= 3;x = x * 3;
x /= 3;x = x / 3;
x %= 3;x = x % 3;

++ เพิ่มค่าทีละ 1 และ -- ลดค่าทีละ 1 ตำแหน่งของมันมีผลเมื่อใช้ในนิพจน์

a++ กับ ++a ต่างกันยังไง

เปรียบเทียบและตรรกะ

ตัวดำเนินการเปรียบเทียบ < <= > >= == != ให้ผลเป็น true หรือ false

ข้อความ (String) ห้ามเทียบด้วย == ให้ใช้ name.equals("Aump") เพราะ == เทียบว่าเป็น object ตัวเดียวกันหรือเปล่า ไม่ได้เทียบตัวอักษร

ตัวดำเนินการความหมายเป็น true เมื่อ
&&และ (AND)จริงทั้งสองฝั่ง
||หรือ (OR)จริงอย่างน้อยหนึ่งฝั่ง
!ไม่ (NOT)กลับค่าจริงเป็นเท็จ เท็จเป็นจริง
^XORสองฝั่งต่างกัน

&& และ || เป็นแบบ short-circuit ถ้ารู้ผลจากฝั่งซ้ายแล้วจะไม่ประเมินฝั่งขวาเลย ส่วน & กับ | ประเมินทั้งสองฝั่งเสมอ งานทั่วไปให้ใช้ && และ ||

int count = 0;
boolean ok = (count != 0) && (10 / count > 1); // false และไม่หารด้วย 0 เพราะหยุดตั้งแต่ฝั่งซ้าย

ตัวดำเนินการระดับบิต

& | ^ ~ ทำงานกับเลขฐานสองทีละบิต ส่วนตัวเลื่อนบิตมี << เลื่อนซ้าย, >> เลื่อนขวาแบบรักษาเครื่องหมาย และ >>> เลื่อนขวาแบบเติม 0

int x = 8;          // 0000 1000
int a = x >> 1;     // 4   เหมือนหาร 2
int b = x << 2;     // 32  เหมือนคูณ 2 ยกกำลัง 2
int c = x >> 32;    // 8   int ใช้จำนวนเลื่อน mod 32 จึงไม่เลื่อนเลย

>> n เท่ากับหาร 2 ยกกำลัง n เฉพาะเลขบวก ถ้าเป็นเลขลบจะปัดลงไปทางลบ ส่วน byte, short, char จะถูกแปลงเป็น int ก่อนเลื่อน

ไม่แน่ใจเมื่อไหร่ ให้ใส่วงเล็บ โค้ดอ่านง่ายกว่าจำตาราง ลองคิดก่อนเปิดเฉลย

int x = 2 + 3 * 4 - (7 + 2); ได้เท่าไร

5 วงเล็บก่อนได้ 9, คูณก่อนบวกได้ 12, จากนั้น 2 + 12 - 9 = 5

int y = 5 - 3 * (6 / (5 + (5 + 3)) * 4 + 2) / 10; ได้เท่าไร

5 เพราะ 6 / 13 เป็น int หาร int ได้ 0 ในวงเล็บจึงเหลือ 0 * 4 + 2 = 2, แล้ว 3 * 2 = 6, 6 / 10 ได้ 0, สุดท้าย 5 - 0 = 5 ถ้าเปลี่ยนเป็น double จะได้ประมาณ 3.846

String result = (score >= 50) ? "ผ่าน" : "ไม่ผ่าน"; ทำงานยังไง

ถ้าเงื่อนไขในวงเล็บเป็นจริงได้ค่าหลัง ? ถ้าเป็นเท็จได้ค่าหลัง : เป็นทางลัดของ if-else ที่ต้องการแค่เลือกค่า

การแปลงชนิดข้อมูล

Widening คือแปลงจากชนิดเล็กไปใหญ่ Java ทำให้อัตโนมัติ ตามลูกศรนี้

byte → short → int → long → float → double
              char ↗

ในนิพจน์คณิตศาสตร์ ถ้ามี double ผลเป็น double, ถ้าไม่มีแต่มี float ผลเป็น float, ถ้ามี long ผลเป็น long นอกนั้นผลเป็น int เสมอ ดังนั้น byte + byte ได้ int

แปลงได้เองไหม

Narrowing ต้อง cast เอง

แปลงจากใหญ่ไปเล็กต้องเขียน (ชนิดที่ต้องการ) ไว้หน้าค่า และอาจเสียข้อมูล

int x = (int) 3.99;                  // 3 ตัดเศษทิ้ง ไม่ปัด
long r = Math.round(3.99);           // 4 ถ้าอยากปัดให้ใช้ Math.round
byte small = (byte) 200;             // -56 เพราะเกินช่วงของ byte

แปลงข้อความเป็นตัวเลข

ข้อมูลที่รับจากช่องกรอกใน GUI เป็น String เสมอ ต้องแปลงก่อนคำนวณ

int n = Integer.parseInt("42");
double d = Double.parseDouble("2.5");
String s = String.valueOf(n);        // ตัวเลขกลับเป็น String
