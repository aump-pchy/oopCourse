Java ฉบับลงมือทำ

เขียน Java ให้เป็น
ทีละหน่วย

บทเรียนวิชา 31901-2006 การพัฒนาซอฟต์แวร์เชิงวัตถุ อ่านทวนได้ทุกที่ ลองเล่นตัวอย่างในหน้า แล้วทำ Exit Ticket ก่อนออกจากคาบ

เริ่มหน่วยที่ 1

บทเรียน

  1. 1

    ภาษาจาวาและเครื่องมือพัฒนา

    JDK JRE JVM, ติดตั้ง JDK 25 และ NetBeans 31, โปรแกรมแรกแบบ Console และ GUI

    เช็กลิสต์ 0/6ยังไม่ทำ Exit Ticket
  2. 2

    ตัวแปร ตัวดำเนินการ และการแปลงชนิดข้อมูล

    ชนิดข้อมูล, การตั้งชื่อ, ขอบเขตตัวแปร, ตัวดำเนินการ 4 กลุ่ม, widening และ casting

    เช็กลิสต์ 0/6ยังไม่ทำ Exit Ticket
  3. 3

    คำสั่งเลือกทำ if และ switch

    if, if-else, else-if, if ซ้อน, switch ทั้งสองแบบ, debugger และเกมทายตัวเลข

    เช็กลิสต์ 0/10ยังไม่ทำ Exit Ticket
  4. 4

    คำสั่งวนซ้ำ

    while, do-while, for, break, continue, loop ซ้อน, สะสมค่า และงานเลขคู่/คี่ในช่วง

    เช็กลิสต์ 0/10ยังไม่ทำ Exit Ticket

แผนกวิชาเทคโนโลยีสารสนเทศ วิทยาลัยเทคนิคเลย

ความคืบหน้าและผล Exit Ticket บันทึกไว้ในเบราว์เซอร์เครื่องนี้เท่านั้น
