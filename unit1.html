Java คืออะไร

Java เป็นภาษาเชิงวัตถุที่ Sun Microsystems เปิดตัวในปี 1995 ปัจจุบัน Oracle ดูแลร่วมกับชุมชน OpenJDK ออกเวอร์ชันใหม่ทุก 6 เดือน และมีรุ่น LTS (ซัพพอร์ตระยะยาว) ทุก 2 ปี รุ่นที่เราใช้คือ Java 25 LTS

เราเจอ Java ได้ในแอปธนาคาร แอป Android เกม Minecraft และระบบหลังบ้านขององค์กรใหญ่

จุดเด่นหมายความว่า
ฟรีและ open sourceดาวน์โหลด JDK ใช้ได้ไม่เสียเงิน
Write once, run anywhereคอมไพล์ครั้งเดียว ไฟล์เดียวกันรันได้ทั้ง Windows, macOS, Linux
เชิงวัตถุโค้ดทุกอย่างอยู่ในคลาส ซึ่งเป็นหัวใจของวิชานี้
Garbage Collectorคืนหน่วยความจำที่ไม่ใช้แล้วให้อัตโนมัติ

แพลตฟอร์มหลักตอนนี้คือ Java SE (ที่เราเรียน) และ Jakarta EE สำหรับระบบฝั่งเซิร์ฟเวอร์ ส่วน Java ME สำหรับมือถือรุ่นเก่าเลิกใช้ไปแล้ว

ติดตั้ง JDK 25

      
ใช้ Eclipse Temurin 25 ฟรีและเป็น open source เลือกระบบของเครื่องตัวเอง

      

        

          
          
        

        

          
    
            
  1. ดาวน์โหลดไฟล์ .msi แบบ x64 แล้วดับเบิลคลิก
    2. 
            
  2. หน้า Custom Setup ให้ตรวจว่าเลือก Add to PATH แล้ว และเลือก Set JAVA_HOME variable เพิ่ม
    3. 
            
  3. กด Install จนจบ
    4. 
            
  4. ปิด Command Prompt ที่เปิดค้างไว้ แล้วเปิดใหม่
    5. 
          

        

        

          
    
            
  1. ดูชิปที่ Apple menu > About This Mac ถ้าเป็น Apple M ให้โหลด aarch64 ถ้าเป็น Intel ให้โหลด x64
    2. 
            
  2. เปิดไฟล์ .pkg กด Continue แล้ว Install ใส่รหัสผ่านเครื่อง
    3. 
            
  3. เปิด Terminal ใหม่ (Cmd+Space แล้วพิมพ์ Terminal) ไม่ต้องตั้ง PATH เอง
    4. 
          

        

      

      
ตรวจผลการติดตั้ง ต้องเห็นเลข 25 ทั้งสองบรรทัด

      
java -version
javac -version

      

        ขึ้น 'javac' is not recognized หรือ command not found
        
Windows: ปิดแล้วเปิด terminal ใหม่ ถ้ายังไม่ได้ให้รันตัวติดตั้งซ้ำแล้วเลือก Add to PATH ถ้าขึ้นเลข 8 หรือ 17 แปลว่ามี Java เก่าอยู่ พิมพ์ where java เพื่อดู แล้วถอน Java เก่าออก

        
macOS: พิมพ์ /usr/libexec/java_home -V ถ้าไม่มี 25 ให้ติดตั้ง .pkg ใหม่ให้ตรงชิป

      

    


    

      
โปรแกรมแรกใน Terminal

      
สร้างโฟลเดอร์ java-lab แล้วสร้างไฟล์ Hello.java ชื่อไฟล์ต้องตรงกับชื่อคลาสทุกตัวอักษร

      
public class Hello {
    public static void main(String[] args) {
        System.out.println("Hello World");
        System.out.println("สวัสดี วิทยาลัยเทคนิคเลย");
    }
}

      
cd java-lab
javac Hello.java
java Hello

      
Notepad ชอบบันทึกเป็น Hello.java.txt ให้เลือก Save as type: All Files ส่วน TextEdit บน Mac ให้กด Format > Make Plain Text ก่อนบันทึก

      
ทางลัดของ Java 25

      
ไฟล์สั้น ๆ ไม่ต้องมีคลาสก็ได้ และรันไฟล์ .java ตรง ๆ ได้เลยโดยไม่ต้อง javac เหมาะกับการลองโค้ดเร็ว ๆ แต่งานในวิชานี้ยังเขียนแบบมีคลาสเป็นหลัก

      
void main() {
    IO.println("Hello จาก Java 25");
}
